    GUIDED SETUP

    Set up the live scoreboard reader

    Step 1 of 5
    1. 1Window
    2. 2Capture
    3. 3Auto-detect
    4. 4Live reads
    5. 5Overlay

    WELCOME & GAME WINDOW

    Start with the correct game window

    Open College Football 27 in Borderless mode, enter a game, and select its window underneath this guide. Keep the supported native scorebug visible while you set up the reader.

    • Use the same supported scorebug layout as the reader profile.
    • Keep the game visible and choose its window, not a launcher.

    CAPTURE GEOMETRY

    Confirm the native game-window shape

    The app reads the game window at its real aspect ratio and chooses the closest height preset. A 3440 x 1440 ultrawide window uses the 1440p size preset without being stretched to 16:9.

    • Use the game render height, not only the monitor label.
    • Ultrawide, widescreen, and custom window widths are supported.

    AUTOMATIC SCOREBUG DETECTION

    Confirm the app found the scorebug

    The amber box shows the outer crop measured from the current game pixels. No manual placement or reader-file export is required for normal use.

    • The complete scorebug should sit inside the amber outline.
    • Use optional tuning only if an individual inner field box needs adjustment.

    VERIFY LIVE READS

    Confirm the reader sees the scoreboard

    With the scorebug visible, confirm both teams and scores, quarter, game clock, and down-and-distance appear in the Home preview.

    • Wait for several complete reads on a slower computer.
    • If values stay blank, check the CAPTURE tile and refresh the live reader view.

    PLACE OVERLAY & FINISH

    Put the overlay where you want it

    Show the overlay, choose Move overlay, drag it into position, and save that position. Turn Automatic visibility back on if you want it to follow the native scorebug.

    • Verify the overlay appears on the same display as the game.
    • Finish only after its position and live values look correct.
    Ready to begin

    Open the game in Borderless mode and keep its live scorebug visible.
