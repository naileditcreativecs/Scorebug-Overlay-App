In Claude, download “Standalone HTML.” Choose one self-contained .html file. Do not choose Project HTML, a ZIP, or a .dc.html file that needs support.js.
Exact HTML requirements for live game data

Keep CSS, JavaScript, SVG, fonts, and images inside the one HTML file. Put data-cfb27-scorebug on the visible scorebug root. For reliable updates, mark fields with data-cfb27-bind.

away.name away.nickname away.rank away.record away.score away.timeouts away.possession away.logo home.name home.nickname home.rank home.record home.score home.timeouts home.possession home.logo game.quarter game.clock game.playClock game.downDistance

Each standalone HTML can declare its own canvas shape. The game-reading boxes stay independent from the selected scoreboard design.

    DYNASTY SAVE

    Matchup context from the save

    Waiting for the first read…

    Bugs get away/home.record and rank filled from the save when the reader has not confirmed them yet, plus confRecord, streak, season.* (yards per game, 3rd-down %, turnovers…), leaders.qbLine/rbLine/wrLine, and game.context (week label, bowl, playoff, network, weather, rematch, conference game).

    TEST GAME NOTES

    What you saw (send with the package)

    Type as you go; Save notes writes them next to the probe files. After the game, Export test package zips everything (probe logs, notes, latest-state, app logs) to your Desktop and opens the folder - send that one file.
