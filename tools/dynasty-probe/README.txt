CFB27 Dynasty Probe (read-only)
Needs Node.js (https://nodejs.org). Double-click "Run Dynasty Probe.cmd", or drag a DYNASTY save onto it.
It reads the newest DYNASTY save in Documents\EA Sports College Football 27\saves and writes dynasty-probe.json:
week/type/year, your team's game this week (opponent, ranks, records, bowl/playoff, network, weather),
both teams' season + per-game stat totals, sample player season/game lines, and a jersey->name roster sample.
Nothing is written to the save.
