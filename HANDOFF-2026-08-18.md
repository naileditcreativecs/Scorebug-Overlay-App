## What the product is
Electron app ("Scorebug Center") + read-only C# RAM reader for EA College
Football 27. The reader publishes the live scoreboard (fail-closed: never
guesses); the app renders HTML "bugs" (scorebugs) from a library, with an
in-game editor (Ctrl+Alt+O), colours/logos per team, and now Dynasty-save
context. Users run it from a zip; testers use the Desktop folder
`C:\Users\craft\Desktop\CFB27 Scoreboard Overlay v1.4.35\` (newest zip + docs;
inner `CFB27-Scoreboard-Overlay-v1.4.44\` is the local test install, kept
current despite the folder name).
